# 界面改版说明（2026-11）

这一次改版只动界面与交互，占卜算法、牌面素材、牌阵定义与数据文件都没有改。

- 原来的样式表 `css/styles.css` 完整保留，改版是一层叠加：`index.html` 的 `<html>` 加了 `class="ui2"`，新样式全部写在 `css/redesign.css` 里并以 `html.ui2` 开头，所以旧规则仍然生效、随时可以整层删掉退回旧版。
- 所有新增文案都进了 `js/i18n.js` 的中英双语块，新增交互都走现有模块，不引入构建工具、不新增依赖。

## 一、页面结构

改版前，首屏几乎被「抽牌设置」的表单占满，牌堆被压到屏幕下方，设置、牌桌、牌阵、结果、版权像五块一样的玻璃卡片叠在一起，没有主次。

改版后按「品牌 → 牌桌 → 使用说明 → 高级设置 → 页脚」排：

| 区域 | 变化 |
| --- | --- |
| 顶栏 `.masthead` | 左品牌、右动作（EN · 占卜历史 · 公告 · 高级设置），底部一条细线，标题只用一种字号、一种颜色 |
| 牌桌 `.table-area` | 抽牌与牌阵合并成一块：标题为「01 抽牌 / 牌桌」，下面是环抱牌阵的扇形牌堆 |
| 牌位说明 `#positionGuide` | 从页首挪到牌桌之后，默认展开，两列排布 |
| 高级设置 `#settingsPanel` | 不再常驻首屏，改为点顶栏按钮弹出的面板；内部所有下拉框换成可左右拖动、可点击的多档开关 |
| 页脚 `.footer` | 三列信息 + 一条整宽的引文带 + 隐私与统计脚注，左对齐，不再是居中的小字墙 |

## 二、牌桌：扇形环抱牌阵

- 78 张牌在一段椭圆弧上排开，弧线包住中间的牌阵，牌堆与牌阵不再是两个分开的区块。
- 左右拖动翻看牌堆，**滑到底会硬停**（不再无限转圈）；拖动反向会有一点回弹。
- 轻点任意一张牌抽出，牌飞进对应的牌位；手指在窄屏上按下的位置有 34px 的容错，不需要精确点中那条细边。
- 弧上只显示当前视口容得下的张数（桌面约 24–36 张，窄屏更少），窗口缩放或牌堆变少时会自动重排，不会把牌挤成一团。
- 「洗牌」不再有第二个重复按钮（原来底部「重新洗牌」和右上角「洗牌」是同一个动作，底部的已删除）。点洗牌会先确认是否清空桌面，确认后播放「聚拢 → 旋转混合 → 收成一叠 → 从左往右摊开」的动画。

## 三、视觉系统

- 主色改为纸与金：底色 `#0a090d`，强调色 `#cba86b`；正文 `#ece5d6` / `#b3a995` / `#8a8172` 三级，分隔线统一为 12% 透明度的细线。
- 字体：标题用 `Noto Serif SC` 衬线，正文用 `Noto Sans SC`；去掉了原来下载不到、只能回退到宋体的 `Cinzel`，也去掉了大字距与小字号。
- 按钮只有两种：金色的主按钮，和只有描边的次按钮。所有渐变、发光、扫光动画都去掉了。
- 字号收敛为 12 / 13 / 14 / 15 / 18 / 19 / 21 / 25 几档，不再一屏十几种。

## 四、七套主题

`celestial 星夜秘境`、`parchment 羊皮纸`、`ember 余烬`、`grove 林地`，新增 `jade 青玉纸`（浅色）、`dusk 暮紫`、`ash 素灰`。

- 切换方式改了：右下角原来那颗磨砂玻璃按钮已移除，改为**轻点右上角的月亮/太阳**切换下一个主题，切换时右下角浮出一行主题名。
- 月亮可以拖动摆放，拖过不会再误触发切换；键盘聚焦后按 Enter / 空格也能切。
- 浅色主题（羊皮纸、青玉纸）里牌位、开关轨道这些原本写死的深色背景改成了按主题计算的变量，不再是黑块。

## 五、自由画板

牌阵设置里的「设计或导入牌阵」换成了「自由画板」，牌的选择方式和有预设牌阵时完全一样：

- 扇形牌堆仍然留在牌桌上当取牌源；
- **双击**扇形里的一张牌，它就落到下方画板上；
- 在画板上**拖动**改变位置；
- **长按**一张牌，它会每 0.3 秒转 15°，松手停止；
- 不再提供缩放/平移视口，牌意统一用「一键开牌」后再看。

## 六、彩蛋

原作者的彩蛋是：60 秒内点 10 下月亮或太阳，月亮会露出坑纹里的脸（羊皮纸主题是太阳睁开眼）。

现在改成**长按 5 秒**触发，同样只切换那张脸的状态；短按仍然是切换主题，拖动不会触发。

## 七、改动的文件

新增：

- `css/redesign.css` — 全部新样式（按 §1…§22 分节：变量、顶栏、牌桌、扇形、牌阵、结果、设置、页脚、弹窗、自由画板、主题、响应式）
- `js/deck-ring.js` — 扇形布局、拖动与惯性、点击命中、洗牌动画

- `docs/ui-refresh.md` — 本文

修改：

- `index.html` — 结构重组、新增按钮与弹层、按版本号引用新资源
- `js/app.js` — 牌桌与自由画板的状态同步、洗牌确认与动画事件、牌阵说明默认展开
- `js/free-board-ui.js` — 新增 `drawAt()`、导出旋转、可关闭缩放

- `js/theme.js` — 七套主题
- `js/i18n.js` — 所有新增中英文案

删除：`js/theme-fab.js`（右下角主题按钮）。

## 八、本地查看

纯静态站点，直接打开 `index.html` 即可，不需要构建：

```bash
# 任选其一
python -m http.server 8000
npx serve .
```

然后访问 `http://localhost:8000/`。

改样式或脚本后请同步修改 `index.html` 里资源后面的 `?v=...` 版本号，否则浏览器会继续用缓存里的旧文件。

## 九、已知限制

- 手机上一屏仍会用到 8 种字号（12–25px），虽然没有视觉错乱，但严格来说还可以再压。
- `--moon-opacity` 只在 celestial / parchment / ember / grove 四个主题里定义，jade / dusk / ash 走的是兜底值。
- 自由画板的手势（双击取牌、长按旋转）只做了结构与视觉验证，还没有真机手感的回归测试。
- 洗牌动画尊重系统的「减少动态效果」设置：开启后会播放一个约 800ms 的快版本，而不是完全不动。
