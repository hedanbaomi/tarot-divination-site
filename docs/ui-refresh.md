# 界面改版说明（2026-11）

本文只说明**最终这次提交与仓库原有代码**的差别：改了什么、现在是什么样、为什么这么改。中间迭代过的过程不在此列。

改版只动界面与交互：占卜算法、牌面素材、牌阵定义、历史记录格式都没有改。

- 在「高级设置 → 页面版本」点「切回旧版」可打开原来的横向牌堆和自由画板。旧版的「抽牌设置」里可以切回新版。同一浏览器会记住选择。两版共用占卜历史和自定义牌阵，分别保存自由画板草稿。
- 旧版入口是 `classic.html`。页面结构、旧版牌桌和天体交互取自改版前的 `6ff79d0`。牌面、牌阵定义、自定义牌阵和历史存储模块与新版共用。
- 新增文案都进了 `js/i18n.js` 的中英双语块；不引入构建工具，不新增依赖。

## 一、页面结构对比

原来首屏几乎被「抽牌设置」的表单占满，牌堆被压到屏幕下方；设置、牌桌、牌阵、结果、版权是五块一样的玻璃卡片叠在一起，没有主次。

现在按「品牌 → 牌桌 → 牌位说明 → 页脚」排，设置收进顶栏弹出的面板：

| 区域 | 原来 | 现在 |
| --- | --- | --- |
| 顶栏 | 居中标题 + ☽☾ 装饰 + 副标题 | 左品牌、右动作（EN · 占卜历史 · 公告 · 高级设置），底部一条细线，标题一种字号一种颜色 |
| 抽牌设置 | 常驻首屏，两块玻璃面板 | 收进顶栏「高级设置」弹出的面板，内部下拉框换成多档开关 |
| 牌桌 | 牌堆与牌阵是两个独立区块，中间隔着一屏 | 合并成一块「01 抽牌 / 牌桌」：扇形牌堆环抱牌阵 |
| 牌位说明 | 折叠在页首 | 挪到牌桌之后，默认展开，两列排布 |
| 页脚 | 居中的一小墙 0.66rem 小字 | 两列信息 + 一条整宽引文带 + 隐私与统计脚注，左对齐 |

## 二、牌桌：扇形环抱牌阵

- 牌堆不再是横向滚动条，而是沿一段椭圆弧排开，弧线包住中间的牌阵；牌堆与牌阵在同一个舞台里。
- 左右拖动翻看牌堆，**滑到两端会硬停**（原来可以无限转圈），反向拖动有一点回弹。
- 牌堆正上方有一对圆形箭头（‹ ›），点一下整圈平滑转过一张牌（缓出 320ms），到头那一侧按钮会变灰禁用，再按没有动画、牌堆不动。
- 轻点任意一张牌抽出，牌飞进对应牌位；窄屏上按下位置有 34px 容错，不必精确点中细边。
- 弧上只显示视口容得下的张数（桌面约 24–36 张，窄屏更少）；窗口缩放或牌堆变少时自动重排，不会挤成一团。
- 弧上的牌一律平面、径向旋转，最左最右是横着的，没有 3D 倾斜。
- 「重新洗牌」按钮已删（原来底部那个和右上角「洗牌」绑的是同一个动作，重复）。
- 点「洗牌」时：桌上有牌先弹确认（按钮为「保留 / 清空并洗牌」），确认后播放「聚拢 → 旋转混合 → 收成一叠 → 从左往右摊开」的动画；空桌直接洗，不弹窗。

## 三、自由模式

不套用牌阵时，牌桌就是一张空桌：

- 牌阵设置里的「自由画板」入口点一下切到自由模式；扇形牌堆仍留在牌桌上当牌源，「设计或导入牌阵」保留在它旁边。
- **单击一张牌**，它就落到扇形下方的桌面上；按 4 列（手机 2 列）自动排开，第 13 张也不会压住第 1 张。
- **拖动**改变位置，可以拖到桌上任何地方；**单击牌面**翻到正面，翻开的牌在下方「解读」里给出牌名、正逆位、关键词和牌意，再点不会盖回去。
- 翻开时用的正逆位就是抽牌那一刻定下的方向，撤销 / 重做也沿用同一个方向。
- 左下角有 `↶` 撤销 / `↷` 重做：撤销把最近抽出的牌放回牌堆，重做再拿回来。
- 自由模式下牌桌下方留出大片空白（`min(62vh, 640px)`，手机 520px）专门给牌摊开用。
- 洗牌会重洗整副牌（不继承预设牌阵剩下的牌），有牌时先问一句，确认框里的保留按钮写「保留」。
- 切到自由模式、抽牌、拖牌、翻牌都会存草稿，刷新后原样回来；旧画板的草稿也能接着恢复。开完牌会写一条历史记录。
- 键盘：牌桌可聚焦，`←/→` 翻动牌堆、`Home/End` 跳到两端、`Enter` 抽中间那张；抽出的牌 `Tab` 可聚焦，`Enter` / 空格翻面；未翻开的牌不会把牌名读给读屏软件。
- 在「牌阵设置」里点「返回预设牌阵」即可回到当前选择的牌阵。自由画板的进度保存在本地，再次点「自由画板」时恢复。
- 抽出来的牌复用牌阵卡片同一套 DOM 与类名，所以牌面、牌背、卡角、字体都跟当前主题、当前牌组（韦特 / Mystagogos / LXXXI）一致，M 牌和 LXXXI 在自由桌面上同样显示自己的牌背。

## 四、视觉系统

- 主色改为纸与金：底色 `#0a090d`，强调色 `#cba86b`；正文 `#ece5d6` / `#b3a995` / `#8a8172` 三级，分隔线统一为 12% 透明度的细线。
- 字体：标题用 `Noto Serif SC` 衬线，正文用 `Noto Sans SC`；去掉了原来下载不到、只能回退到宋体的 `Cinzel`，也去掉了大字距与小字号。
- 按钮只有两种：金色主按钮，和只有描边的次按钮；原来的渐变、发光、扫光动画都去掉了。
- 字号收敛为 12 / 13 / 14 / 15 / 18 / 19 / 21 / 25 几档，不再一屏十几种。

## 五、七套主题

`celestial 星夜秘境`、`parchment 羊皮纸`、`ember 余烬`、`grove 林地`，新增 `jade 青玉纸`（浅色）、`dusk 暮紫`、`ash 素灰`。

- 切换方式改了：右下角原来那颗磨砂玻璃按钮已移除，改为**轻点右上角的月亮/太阳**切换下一个主题，切换时右下角浮出一行主题名。
- 月亮可以拖动摆放，拖过不会误触发切换；键盘聚焦后按 Enter / 空格也能切。
- 浅色主题（羊皮纸、青玉纸）里牌位、开关轨道这些原本写死的深色背景改成了按主题计算的变量，不再是黑块。

## 六、彩蛋

原作者的彩蛋是：60 秒内点 10 下月亮或太阳，月亮会露出坑纹里的脸（羊皮纸主题是太阳睁开眼）。

现在改成**长按 5 秒**触发，同样只切换那张脸的状态；短按仍然是切换主题，拖动不会触发。

按住约 0.2 秒后月亮外面会出现一圈很淡的描边，表示正在计时；手指移动 22px 以内不会中断（原来的轻点容差只有 12px）。如果系统在 5 秒附近抛 `pointercancel`（触屏长按菜单会这样），松手时也会补触发一次。Jade / Dusk / Ash 三套新主题同样显示这张脸。

## 八、本地查看

纯静态站点，直接打开 `index.html` 即可，不需要构建：

```bash
# 任选其一
python -m http.server 8000
npx serve .
```

然后访问 `http://localhost:8000/`。

改样式或脚本后请同步修改 `index.html` 里资源后面的 `?v=...` 版本号，否则浏览器会继续用缓存里的旧文件。

## 九、已知限制

- 手机上一屏仍会用到 8 种字号（12–25px），没有视觉错乱，但严格来说还可以再压。
- 自由模式的抽牌池、正逆位、草稿恢复、历史写入、13 张排布和可访问性都有自动化测试；手感（拖动阻尼、长按翻面）仍是在无头浏览器里用指针事件验证的，真机未回归。
- 洗牌动画尊重系统的「减少动态效果」设置：开启后会播放一个约 800ms 的短版本，而不是完全不动。
